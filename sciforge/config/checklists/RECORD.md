# RECORD — Estudos com dados coletados rotineiramente (extensão do STROBE)

Fonte: Benchimol EI, et al. The REporting of studies Conducted using Observational Routinely-collected health Data (RECORD) Statement. PLoS Med 2015. Itens parafraseados; aplicar junto com todos os itens do STROBE.

- **1.1** [Título/Resumo]: Especificar o tipo de dados utilizados e, quando possível, o nome das bases.
- **1.2** [Título/Resumo]: Se aplicável, informar a região geográfica e o período abrangidos.
- **1.3** [Título/Resumo]: Se houve vinculação (linkage) entre bases, declarar isso no título ou resumo.
- **6.1** [Métodos]: Detalhar os métodos de seleção da população (códigos, algoritmos) usados para identificar indivíduos.
- **6.2** [Métodos]: Citar estudos de validação dos códigos/algoritmos de seleção; se feita validação própria, relatar métodos e resultados.
- **6.3** [Métodos]: Se houve linkage, incluir fluxograma ou diagrama da vinculação, com número de indivíduos em cada etapa.
- **7.1** [Métodos]: Fornecer lista completa de códigos e algoritmos usados para classificar exposições, desfechos, confundidores e modificadores.
- **12.1** [Métodos]: Descrever o grau de acesso dos autores à base de dados usada para criar a população.
- **12.2** [Métodos]: Fornecer informações sobre a limpeza de dados utilizada no estudo.
- **12.3** [Métodos]: Declarar se houve vinculação individual, por probabilidade ou outro método, e avaliar sua qualidade.
- **13.1** [Resultados]: Descrever em detalhe a seleção das pessoas incluídas, incluindo filtragem por qualidade, disponibilidade e linkage (fluxograma).
- **19.1** [Discussão]: Discutir implicações do uso de dados não criados para responder à pergunta de pesquisa: erro de classificação, confundimento não medido, dados faltantes e mudanças de elegibilidade ao longo do tempo.
- **22.1** [Outras informações]: Informar como acessar protocolo, dados brutos ou código de programação.
